The main purpose of this project is to recreate 研报中心 section in 新浪财经 app

The difference is: 新浪财经 app uses xml to build the UI for the app,
    however, this project uses a new technology: Jetpack Compose to build the UI

Jetpack Compose is Android’s modern, fully declarative UI toolkit built entirely in Kotlin. 
    It allows developers to describe UI components in code using simple functions annotated 
    with @Composable. Instead of managing XML layouts and imperative view updates, Compose 
    automatically updates the UI in response to state changes, reducing boilerplate and 
    improving maintainability. It integrates seamlessly with Kotlin’s features, provides 
    real-time previews, and promotes a more intuitive way to build responsive, dynamic interfaces 
    on Android.
